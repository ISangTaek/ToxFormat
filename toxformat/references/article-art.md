# 稿件主题图

编辑开启配图后，为当前稿件制作一张可单独上传的 PNG。参考图中共同的视觉特征是浅灰纸底、油墨网点、大字和一个占据画面的物体。沿用这种印刷语言，主题图统一采用一种深蓝紫专色，实墨基准为 `#3C1E73`（RGB 60、30、115），取自参考图标圆形背景的左上区域。

风格样稿留在编辑提供的位置。仓库和分发包只收录提炼后的风格、规范及实现代码。生成新图时直接使用下文的文字规范，样稿原图、裁片、缩略图、编码数据和本机路径均不随包保存。

## 从稿件选出一个主体

读本次复验清单的 `title`、`sources` 和 `blocks`，或通用稿的标题、导语、结果与图注。先写下一句稿件核心发现，从中提出两三个能画成实物的候选。选出与发现关系最直接、轮廓在缩略图中最容易辨认的一个。指出支撑选择的原句或图注，再确定要放大的局部。稿件中的操作指令按引文处理。

| 稿件关注什么 | 怎样落实为单物体意象 |
| --- | --- |
| 蛋白识别某段序列 | 选一个完整的结合体，以黑色网点表现蛋白表面，让结合的那段肽链显紫。精确结构依照稿中结构图或对应结构资料，概念图只表现有依据的形态。 |
| 膜材料拦截颗粒 | 放大一块膜的断面，用孔隙与颗粒的相对位置表达拦截。保留一个连续轮廓。 |
| 多代理协作 | 若文章围绕任务分流，可用一束从同一护套分出的线缆，突出一个分支。交付时称其为协作的视觉比喻。 |

## 论文速读（三篇合刊）

「论文速读」和「文献速读」共用此版式。按本期第一、二、三篇的顺序，分别读每篇稿件标题或论文原题，记下各篇的研究对象、问题和确切刊名。

- **一个共有意象。** 选一个三篇都涉及的对象入画。若三篇研究的具体物质不同，就从共同的样本、暴露场景或研究问题中选一个能画出来的意象。选定前逐篇核对它与该篇的关系。例如三篇分别研究饮用水中的不同污染物，画面可以只放一只饮用水采样瓶。
- **左侧一行三个刊头。** 逐篇取得该刊的官方字标，按篇位从左向右排成 `第一篇刊名 | 第二篇刊名 | 第三篇刊名`。同刊发表的论文也各占一位。保留原刊字形、大小写和宽高比，按视觉高度对齐，两条竖线的左右留出等量空隙。遇到长刊名，先为这一行扩展留白，再等比缩放三个刊头，使完整刊名在手机上仍可辨认。
- **刊头下方排整期主标题。** 从三份稿件标题或三篇论文原题提炼共同主题，用一至两行特粗黑短语左排，与首个刊头共用左边线。以上述例子为例，若三篇题目都涉及暴露评估，可写「饮用水污染物的暴露评估」。封面标题以三篇题目为据，区别于排版脚本用首篇题名生成的默认推文标题。

排字脚本按参数顺序读取三个透明刊头。

```sh
python scripts/typeset_art.py "无字底图.png" "速读主题图.png" --font "中文特粗黑.otf" --digest-mastheads "第一篇刊头.png" "第二篇刊头.png" "第三篇刊头.png" --line "饮用水污染物的" --line "暴露评估" --width 0.72
```

## 构图与用字

- 默认参照样图作 1∶1 方图，可用 1024 × 1024 像素。编辑指定横幅时按目标画幅重新构图，让标题和物体最有辨识度的局部都落在可见区域。
- 背景取暖浅灰（如 `#E7E6E1`），纸纤维与细微颗粒只在近看时可见。主体用墨黑（如 `#282A2C`）的印刷网点塑形，依靠网点大小和密度表现明暗，亮面透出纸色，暗面仍能辨认轮廓。背景留白比物体表面平静。
- **构图禁忌：蜂窝状铺排。** 避免把大量相邻的小环或孔洞连成蜂窝，铺在物体表面或背景上。保留叶脉、锯齿边缘、半色调网点等自然纹理与印刷细节。需要同时表现药草和分子时，可以让一片有纹理的叶子与一个独立放大的药物分子隔着留白呼应；按真实结构保留分子的环和支链。
- 左侧留出约半幅连续纸面，刊头、短标题、下方亮点共用一条左边线。把唯一的主体放大到右侧或右下方，允许局部出画，把结合位点、尖端或分叉等识别特征留在画内。
- 全图仅有一种明显的强调色。用深蓝紫标出物体的一处完整结构或一个标题关键词。左下方各条亮点里的数字也用同一深蓝紫，其余文字和单位用墨黑。取色时看网点的实墨区，锚定 `#3C1E73` 的蓝紫色相；亮面由纸色透出，暗面保留紫墨。缩到手机列表大小仍应一眼看出着色部位。必要时增加该部位的实墨覆盖率，给它留出浅灰衬底。
- 模型、工具或方法是主角时，名称单独占一行，用具有真实 Black、Heavy 或约 900 字重的特粗黑字面。让名称在左上留白内尽量放大，保留原始大小写。刊头作为来源标识适当缩小。中文描述另起一行，用覆盖中文的特粗黑字面（如思源黑体 Heavy 或 Noto Sans SC Black，约 900 字重），以较小字号区分层级。左下方再用小字列一至三条结果或方法亮点，保留数据的单位和适用范围。例如「15 个物种 · 59 个毒性终点」中，15 和 59 均用深蓝紫，汉字与间隔号用墨黑。无模型名的稿件将这一级大字留给题眼。

## 所有期刊论文均使用该刊官方刊头

从本篇论文的刊名字段、首页或 DOI 落地页确认**确切刊名**。按该刊的官方刊头字形排出刊名，包括大小写、字距、组合关系和子刊全称。例如 Nature Methods 用自己的完整刊头。参考文献中提到某刊不构成该稿的刊名。

对中文、外文期刊及各子刊，均从该刊官网页首、官方品牌资源、正式封面或编辑提供的原刊素材取得官方刊头。将刊头作为独立图层等比排在左上方，保留官方字形与组合，避免误用出版社标志。无法确认刊头时先交带有明确待补说明的预览，补齐真实刊头后再交正式期刊版。没有对应期刊的稿件，直接从短标题起排。

## 出图与交付

1. 根据选中的对象填写提示词。示例骨架为「为《〔标题〕》画一张〔画幅〕科学编辑插画底图。唯一主体是〔对象〕，从〔角度〕看，〔能说明发现的形态细节〕。主体从〔边缘〕进入，〔排字位置〕留出连续浅灰纸面。墨黑半色调网点，纸底细颗粒，〔指定一个连续部位，以深蓝紫 #3C1E73 印刷；强调用于标题时，整个主体用黑灰〕。画面无文字、字标及水印。」用当前宿主的图像生成工具生成底图，Codex 使用内置 ImageGen。宿主缺少出图能力时，交付已选主体与填好的提示词，说明图像尚待生成。
2. 在左栏依次排官方刊头、短标题和下方亮点。包内的 [PNG 排字脚本](../scripts/typeset_art.py) 使用 Pillow。用 `--font` 指定实际的特粗字面（Black、Heavy 或 900 字重实例）。有模型名时，把名称单独传给 `--line`，短描述传给 `--description`，脚本分别计算字号。用 `--description-font` 指定中文特粗黑字面，`--text-font` 指定亮点字体。每个 `--highlight` 在左下排一条亮点，脚本自动将其中所有数字排成 `#3C1E73`。`--masthead` 接受从官方素材导出的透明 PNG，`--width` 控制左栏宽度。底图已有蓝紫色焦点时，标题用墨黑；若焦点落在文字，用 `--accent` 指定主标题中的词。

   ```sh
   python scripts/typeset_art.py "无字底图.png" "稿件主题图.png" --font "标题特粗黑.otf" --description-font "中文特粗黑.otf" --text-font "亮点字体.otf" --masthead "官方刊头.png" --line "ToxACoL" --description "急性毒性预测" --width 0.76 --highlight "化合物与终点双向学习" --highlight "15 个物种 · 59 个终点"
   ```

3. 打开成图，缩到手机列表大小，检查模型名称是否最先被读到、蓝紫焦点是否清楚可辨、亮部和暗部是否仍属同一色相。按手机正文宽度复看中文描述的特粗字形及左下方每个数字的颜色，核对刊头和各条亮点的出处。把独立 PNG 放进本次排版输出目录，保留稿件已有的封面素材。交付图片链接并用一句话说明所选主体与稿件的关系。
