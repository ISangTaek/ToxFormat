# 稿前检查与证据格式

默认检查 AI 感和错别字，先生成参考报告，随后按原稿出刊。报告的结论不进入正文，也不修改作者标记。AI 感分数衡量本规则捕捉到的模板化语言密度，不能用于推断文章作者身份。

## 如何计分

按篇统计正文、带标签的速读段落、按语和列表句。中文句末标点、英文句末和换行分句，保护小数、常用英文缩写、DOI 和网址。排除引号内引述、书名及登记的专业固定搭配。标题、署名、图注、表格、参考文献、论文信息行、代码和版权说明不计入文风分。去掉保护内容后只剩标点的句子不进入分母。

| 每句观察项 | 分数 |
| --- | --- |
| 出现规则所列的整套铺垫或收尾，如“随着……迅速发展……引起广泛关注” | 1 |
| 同一句有两个以上不同的宣传词，如“全方位”“赋能”“新范式” | 1 |
| 与本篇前两个可评分句之一重复同一登记句首，如“值得注意的是” | 1 |
| 与前两个可评分句之一重复同一修辞框架，如“不仅……而且……” | 1 |
| 明确的模型对话残留，如“以下是根据您的要求撰写的文章” | 直接记 2 |

每句上限 2 分。设有效句数为 N，各句得分之和为 S，总分取 `100 × S / (2 × max(N, 5))` 四舍五入到整数。无有效句标“未评分”。0–24 分提示较少，25–49 分建议局部调整，**50–100 分建议大修**。例如 10 句合计 10 点即为 50 分。报告列出命中原句、位置和依据；合刊同时列出三篇各自的分数及最高分的位置。编辑可回到原句决定如何处理。

实际匹配规则和版本见[规则表](../assets/editorial-rules.json)，调研来源及许可证见[调研记录](research-sources.md)。

## 校对与原始文献核查

1. 逐篇核查所有 `units`，包括标题、署名、图注和表格。结合上下文、同稿用词和稿内拼写校对。专业名词、基因符号、化合物、单位和名字逐一对照定义，证据不足时说明疑点。词表命中会自动并入报告。
默认模式只填写校对记录中的 `typos`。以下事实核查步骤仅在编辑明确要求后执行，命令加 `--fact-check`。

2. 通过原始 DOI、公开期刊页面、PMC、作者提供的全文或补充材料确认文献身份。使用公开题名、DOI 查询，稿件留在本机。按篇读取相关页、小节、图表标题及脚注。摘要仅支持其中明确写出的事实。
3. 用 `inspect` 的 `fact_ids` 和 `units` 定位稿件原句，分别核对数值、单位、指标、样本范围、年份、物种、比较对象及方向。一句含多个事实时拆成连续的原文片段；同义转述按事实含义判断。引言中的政策、期刊影响因子等若超出论文本身的证据范围，在报告中标明所缺材料。纯主观评论、栏目题签可标“无可核事实”。检查完毕后就算全部“待核”也继续排版。
4. 写 UTF-8 JSON。校验值取 `inspect.input_sha256`，三文件合刊的校验值包括篇位顺序。更换文件或调整顺序后重新提取和核对。示例中的位置、文件名、数值都需替换为当次实际材料。

```json
{
  "input_sha256": "从 inspect 原样复制",
  "facts": {
    "d2.p4.s1": [
      {
        "claim": "结果：共记录 42 次观测。",
        "status": "不一致",
        "source": "编辑提供的原文.pdf",
        "locator": "第 3 页，表 1，合计行",
        "evidence": "表中合计为 24 次；稿件写作 42 次。"
      }
    ]
  },
  "typos": [
    {"id": "d1.p5.s1", "word": "数椐", "suggestion": "数据", "why": "与原文定义及本稿方法段的用词一致。"}
  ]
}
```

`claim` 必须能在该句逐字定位。“一致”和“不一致”都需要原文来源、具体定位和依据摘述。“待核”写明已查范围、缺少的证据；“无可核事实”说明原因。缺失的事实行、未覆盖的句内内容和无效证据落入待核；这样报告可展示核查覆盖范围。文件不可用也可以直接执行 `report` 及 `format`，如实说明原文获取情况。
